# Audit log

Audit lets authorized users review what Workgate did: tool calls, administration changes and task activity.

## Review activity

Open the **Audit** panel in the [WebUI](webui.md), select the time range and inspect the event details allowed by your account.

For recent work on a task or session, start in **Tasks and Sessions**.

## Keep and protect records

Audit records may include paths, command output and other project content. Treat exported records and backups as sensitive and limit access to authorized users.

Storage paths and retention are configured through Workgate's [Configuration reference](../reference/configuration.md).

## Missing an event?

Confirm the request reached the intended Control, check the selected time range, and inspect Control logs for errors. See [Troubleshooting](../troubleshooting.md).
